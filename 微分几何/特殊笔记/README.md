# 特殊笔记

本文件夹用于将用户口述的文字转写与按顺序提供的手写公式共同复原为笔记。

- 文字转写可能非常不准确，须与手写公式及上下文结合识别。
- 正文顶部不设总标题，因为整份笔记的主题可能随追加内容变化。
- 章节按文字叙述与对应手写材料的顺序推进；不同份文字叙述按用户提供材料的顺序衔接，不擅自按时间、主题或逻辑重新排序。只有用户明确要求时，才调整指定部分的顺序，此类调整不改变默认约定。
- 删去语气词、无意义的口头成分；有意义的解释和过渡尽量保留原有表达与顺序，不因它只是过渡就删除。
- 几乎不新增解释或过渡，不擅自扩写为教材。口述公式也须写成公式，即使手写未收录。
- 所有识别疑点及原始记录的不一致，统一用对应页下方的小字号脚注记录；脚注专门记录问题，不另建核对说明。
- 本次用户要求优先于根目录的一般笔记约定。此笔记独立于相邻 note 文件夹，不套用该文件的英文术语约定。
- 修改入口：`源码/特殊笔记.tex`；阅读文件：`特殊笔记.pdf`。原始文字及手写材料保存在 `原始材料/`。
- 中文路径的 LaTeX 编译使用 ASCII 临时目录，编译后回存 PDF，编译日志收在 `源码/build/`。
