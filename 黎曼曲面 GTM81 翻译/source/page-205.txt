§25. The Runge Approximation Theorem 
The classical Runge Approximation Theorem asserts that on a simply con-
nected domain Y c C every holomorphic function can be approximated, 
uniformly on compact sets, by functions which are holomorphic on all of C 
(and thus by polynomials). This theorem was generalized by Behnke-Stein 
[51] to arbitrary non-compact Riemann surfaces X. In order to approximate 
all holomorphic functions on an open subset Y c X by functions holomor-
phic on X, one has to replace the assumption that Y is simply connected by 
the assumption that no connected component of X\ Y is compact. The proof 
we present is based on a functional analytic proof using Weyl's Lemma which 
was first given by Malgrange [55].
