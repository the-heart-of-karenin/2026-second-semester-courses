# 拟阵与单纯复形选读

两份原文保存在 `原文/`；两份独立中文 PDF 保存在 `output/pdf/`。

## 翻译范围

- Björner，*Topological Methods*：第 9、11 节全文，含编号条目 9.1—9.20、11.1—11.14，所选部分的定理、公式、证明、文献引注均保留。其余节保留节号和标题占位。原书第 1842—1848、1853—1858 页。
- Samper，*Quasi-matroidal classes of ordered simplicial complexes*：摘要、第 1—3 节、第 4 节开头、第 4.1、4.2 小节，至定理 4.14 及其证明结束。第 4.3、5—8 节及 8.1、8.2 保留节号与标题占位。原 PDF 第 1—17 页的对应内容。

这里是所选分节的翻译，不是摘要。未选内容用留空说明明确标出；文末完整参考文献表未译，可在原文中查阅。原文中的年代性陈述按原稿保留。

建议先读 Samper 第 2 节和第 3 节，再读第 4 节的三个弱化公理及 4.1、4.2；Björner 第 9 节作为术语查阅，第 11 节作为拓扑性质的集中介绍。关于拟阵独立复形的核心结论见 Björner 11.10(iii)。

## 两篇的记号差别

Björner 不将空集算作面，按面维数编号；Samper 将空集算作面，按元素个数计秩，故秩比维数大 1。Samper 原稿对删除、收缩的符号前后不一致，译稿统一写作 `del`、`con`，分别表示诱导删除与取链接的收缩。

## 译注

蓝色“译注”与原文内容分开，说明明显笔误、记号约定及必要的适用范围。例如 Samper 的定理 2.1、2.2 在提供的版本中重复，移位替换式写反，一个回路例子误列了基；这些均在原位置标明。没有擅自将重复定理替换为另一个未经原稿陈述的定理。

## 源码与重建

源码在 `源码/`。在安装有 XeLaTeX、ctex 和 Windows 中文字体的环境中运行：

```powershell
python .\源码\build.py
```

也可在任意目录指定 `build.py` 的完整路径。分别构建时，在命令末尾加 `samper` 或 `bjorner`。默认构建两份，并各编译两遍以更新目录。

`源码/verify.py` 使用 pypdf、Pillow、pdftoppm 检查输出、提取文字并生成逐页预览；检查文件保存在 `build/检查/`。`源码/ocr_source.ps1` 是用于扫描原文转写的辅助脚本。中间提取文字不是最终译稿，公式以原文页图为校对依据。
