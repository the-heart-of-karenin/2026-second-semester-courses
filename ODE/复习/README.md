## 修改源码

- `源码/review.tex`：复习正文。每条用稳定 `kp:` 标签标识，增删条目时直接在此处修改。
- `源码/preamble.tex`：共同版式。
- `源码/standard_questions.py`：当前标准题面主源。`TEXT` 的 1--50 号分别对应本册题号，后续修改题干在此进行。题面列明条件与待证式，分项编号，不含解法提示。
- `源码/exam_revision.py`：定义当前选题、分组、考点及来源。修改出处或更换题目时同步维护此文件与标准题面主源。
- `源码/make_training.py`：保留习题集候选题库，并调用 `exam_revision.py` 生成当前的 `training.tex` 和 `sources.csv`。
- `源码/training.tex`：可直接修改的训练题 LaTeX。但再次运行生成器会覆盖它，题干修改应回到 `standard_questions.py`，分组与来源修改在 `exam_revision.py` 进行。
- `源码/sources.csv`：本册题号与习题集原题号、页码、考点映射。
- `源码/build.py`：在 ASCII 临时目录编译两份文档，再把 PDF 复制回本目录。需要 Python 3 和 XeLaTeX；不需要下载两本书才能重新编译。

在本目录运行：

```powershell
python 源码/make_training.py
python 源码/build.py
```

若只修改复习正文，只运行第二行。目录与书名含中文，禁止直接在中文路径尝试 XeLaTeX；脚本已经统一处理。编译日志位于 `源码/build/`。数学内容全部为文字/公式源码，最终阅读文件不依赖扫描图片。
