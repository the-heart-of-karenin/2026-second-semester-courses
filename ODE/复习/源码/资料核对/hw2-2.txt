2. Bernoulli 方程的零点问题

    Bernoulli 方程为
                      x′ + p(t)x = q(t)xα ,            α > 0,      α ̸= 1.

对于 x ̸= 0，作教材中的代换
                                         y = x1−α .

得到线性方程
                           y ′ + (1 − α)p(t)y = (1 − α)q(t).

    因此要分两种情形讨论。


情形一：α > 1. 此时 1 − α < 0。若存在非零解在某个内点 t0 满足 x(t0 ) = 0，那么在靠近 t0 的
非零一侧，
                                      y(t) = x(t)1−α

应趋于无穷大。可是 y 满足一个系数连续的一阶线性微分方程，其解在有限的内点处可以连续延拓
并保持有限，这与 y(t) → ∞ 矛盾。
    所以
            α > 1 =⇒ x(t0 ) = 0 的解只能是零解，不存在非零解穿过或离开0.


情形二：0 < α < 1. 此时 1 − α > 0，非零解可以在有限时刻到达 x = 0，并且可能与零解拼接。

3. 两个已知解与通解

(a) 一阶线性方程

    设
                                       x′ + p(t)x = q(t)

有两个不同的解 x1 (t), x2 (t)。两式相减得

                                (x2 − x1 )′ + p(t)(x2 − x1 ) = 0.

所以 x2 − x1 是对应齐次方程的一个非零解。齐次方程的一切解都是它的常数倍，因此原方程的通
解为
                                                          
                         x(t) = x1 (t) + C x2 (t) − x1 (t) ,        C ∈ R.

也可写成
                                x(t) = (1 − C)x1 (t) + Cx2 (t).

(c) 比较

   两者最重要的区别是：

  1. 对一阶线性方程，知道两个不同的解以后，不需要再积分，只需作常系数的仿射组合

                         x = (1 − C)x1 + Cx2

    就得到全部解。

  2. 对 Riccati 方程，知道两个不同的解后，虽然已经把求解问题大幅简化，但一般仍需计算一次
    积分               Z
                                              
                          q(t) x1 (t) − x2 (t) dt.

    通解对已知解表现为一个随 t 变化的分式线性（Möbius）关系，而不是简单的线性组合。

   因此可以概括为

     线性方程：两个解 ⇒ 直接仿射组合；             Riccati 方程：两个解 ⇒ 还需一次求积。
