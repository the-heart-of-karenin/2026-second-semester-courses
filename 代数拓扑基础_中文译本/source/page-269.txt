Definition 4.10.13
(1) A loop is a map γ : [0, 1] →X, so it can be considered a
singular 1-simplex in X. Treating γ as a 1-simplex, we see that ∂γ =
x0 −x0 = 0. So γ is a singular 1-cycle, and as such it determines a
homology class. We will denote the homology class of γ by {γ}.
(2) The map
χ : π1(X, x0) →H1(X)
is defined by χ([γ]) = {γ}.
The lemma tells us that χ is a well-defined mapping, so after giving one
more definition, we will be prepared to state our key result relating homology
and homotopy.
Definition 4.10.14 Let G be a multiplicative group. For a, b ∈G, the ele-
ment a−1b−1ab is called the commutator of a and b. The subgroup generated
by the commutators of G is called the commutator subgroup of G.
Theorem 4.10.15 Let X be a topological space and x0 ∈X a base point for
homotopy.
(1) The map χ : π1(X, x0) →H1(X) is a homomorphism of groups.
(2) If X is path-connected, then χ is surjective.
(3) If X is path-connected, then the kernel of the homomorphism is
the commutator subgroup of π1(X, x0).
(4) If X is path-connected, then χ is an isomorphism if and only if
the fundamental group of X is commutative.
Of course, it is immediate from the theorem that if C is the kernel of the
homomorphism [i.e., the commutator subgroup], then π1/C ∼= H1. It is in this
sense that the first homology group is the abelianization of the first homotopy
group.
