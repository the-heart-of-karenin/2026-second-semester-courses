If A is closed in XT , then because Xα is a subspace of XT , the set A ∩Xα
is closed in Xα for each α. It follows that A is closed in XC. Thus the topology
of XC is finer than that of XT .
We next show that each Xα is a subspace of XC. It then follows from its
definition that XC is coherent with the subspaces Xα. For this purpose, we
show that the collection of closed sets of Xα equals the collection of sets of the
form A ∩Xα, where A is closed in XC. By the definition of XC, if A is closed
in XC, then A ∩Xα is closed in Xα. Conversely, suppose that B is closed in
Xα. Because Xα is a subspace of XT , we have B = A ∩Xα for some set A
closed in XT . Because the topology of XC is finer than that of XT , the set A
is also closed in XC. Thus B = A ∩Xα for some A closed in XC, as desired.
(b) As in part (a), we define the topology XC on the set X by declaring A
to be closed in XC if and only if A ∩Xα is closed in Xα for each α.
We show that each Xα is a subspace of XC. It then follows from its defini-
tion that XC is coherent with the subspaces Xα. As before, we show that the
collection of closed sets of Xα equals the collection of sets of the form A∩Xα,
where A is closed in XC. First, if A is closed in XC, then A ∩Xα is closed
in Xα. Conversely, suppose B is closed in Xα. Let β be any index. Because
Xα ∩Xβ is a closed set in Xα, the set
B ∩Xβ = X ∩(Xα ∩Xβ)
is a closed set of Xα. Because Xα ∩Xβ is a subspace of Xα, it is also a closed
set in Xα ∩Xβ. Because Xα ∩Xβ is a closed subspace of Xβ, it is a closed
set in Xβ. Since β was arbitrary, B is by definition a closed set of XC. Thus
B = B ∩Xα, where B is closed in XC, as desired.
Incidentally, we have shown that every closed subset of Xα is also closed
in XC. In particular, Xα is itself closed in XC.
EXAMPLE 4.11.5 Let K be a complex in EJ. Since EJ is a space, |K|
has a topology inherited from EJ. Each simplex σ of K is a subspace in this
topology. By (a) of the preceding lemma, |K| has a topology coherent with
the subspaces σ, which is in general finer than the topology |K| inherits from
EJ. This is a fact we proved directly in Section 1.3.
