If G is an abelian group, an element g of G has finite order if ng = 0
for some positive integer n. The set of all elements of finite order in G is
a subgroup T of G, called the torsion subgroup. If T vanishes, we say G is
torsion-free. A free abelian group is necessarily torsion-free, but the converse
is not true.
If T consists of only finitely many elements, then the number of elements
in T is called the order of T. If T has finite order, then each element of T has
finite order, but again the converse is not true.
