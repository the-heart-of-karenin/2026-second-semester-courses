(d) To define a homomorphism mapping the tensor product A⊗(B ⊗C) into
an abelian group G, we must define a bilinear function f on the set A×(B⊗C).
In order that f be linear in the second variable, it must for fixed a ∈A come
from a bilinear map of the set a × B × C into G. We conclude that a map
f of the set A × B × C into G defines a homomorphism from A ⊗(B ⊗C)
into G precisely if it is linear in each of the three variables separately. Such
a function is called a multilinear function. A similar argument shows that
homomorphisms of (A ⊗B) ⊗C into G are obtained in exactly the same way.
Now consider the functions
