Theorem 2.9.10 If h : Sn →Sn has degree different from 1, then h takes
some point to its antipode.
Proof: If a is the antipodal map as usual, then a◦h has degree different from
(−1)n+1, so it has a fixed point x. Thus a(h(x)) = x or −h(x) = x as desired.
Corollary 2.9.11 The sphere Sn has a non-vanishing tangent vector field if
and only if n is odd.
Proof: First, suppose n is odd. We simply construct an appropriate vector
field as follows: Set n = 2k −1. For x ∈Sn ⊂R2k, we define
v(x) = (−x2, x1, −x4, x3, . . . , −x2k, x2k−1) .
We see that v(x) is perpendicular to x, hence tangent to the sphere at x. Since
∥v(x)∥= ∥x∥= 1, v never vanishes.
For the converse, suppose that w(x) is a tangent vector field to Sn at x
with w(x)̸ = 0 for all x ∈Sn. Then
h(x) =
w(x)
∥w(x)∥
is a map from Sn into Sn. Since w(x) is perpendicular to x for all x, we cannot
have either h(x) = x or h(x) = −x for any x. Thus h has no fixed point,
and Theorem 2.9.9 tells us that deg(h) = (−1)n+1. Also h maps no point to
its antipode, so Theorem 2.9.10 tells us that deg(h) = 1. We conclude that
(−1)n+1 = 1. Thus n must be odd.
