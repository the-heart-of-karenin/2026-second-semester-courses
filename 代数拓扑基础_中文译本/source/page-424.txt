Corollary 7.6.4 If (X, A) is a topological pair such that Hi(X, A) is finitely
generated for each i, then there are natural exact sequences

They split, but not naturally.
The argument used to prove Lemma 7.6.3 might make one suspect that
there is a functorial version of the result. Here is that formulation:
Theorem 7.6.5 Let C be the category whose objects are free chain complexes
C, each of which vanishes below some dimension, and is such that Hi(C) is
finitely generated for each i. Let C′ be the subcategory of C whose objects are
those objects of C whose chain groups are finitely generated in each dimension.
The morphisms in both cases are chain-homotopy classes of chain maps.
If J : C′ →C is the inclusion functor, then there is a functor G : C →C′
such that G ◦J is the identity functor of C′ and J ◦G is naturally equivalent
to the identity functor of C.
