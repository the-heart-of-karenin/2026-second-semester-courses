C1(K) is free abelian of rank 4; the general 1-chain c is of the form c =  niei.

if n1 = n2 = n3 = n4. One concludes that Z1(K) is infinite cyclic, and is
generated by the chain e1 + e2 + e3 + e4. Since there are no 2-simplices in K,

EXAMPLE 1.6.12 Consider the complex L of Figure 1.6.4, whose under-
lying space is a square region [not just the boundary of the square, but the
interior also]. The general 1-chain is of the form c =  niei. One reasons as
in the preceding example to conclude that this 1-chain is a cycle if and only if
n1 = n2, n3 = n4, and n5 = n3 −n2. One can assign values to n2 and n3 ar-
bitrarily, and then the others are determined. Therefore, Z1(L) is free abelian
of rank 2. One possible basis for Z1(L) consists of the chain e1 + e2 −e5,
obtained by taking n2 = 1 and n3 = 0, and the chain e3 + e4 + e5, obtained
by taking n2 = 0 and n3 = 1. This choice of basis is convenient, because
∂2σ1 = e1 + e2 −e5 and ∂σ2 = e3 + e4 + e5. Therefore we have Z1(L) = B1(L)
and
H1(K) = Z1(L)/B1(L) = 0 .
We also have H2(L) = 0. This last equation holds because the general 2-chain
in L is m1σ1 + m2σ2 which is a cycle if and only if m1 = m2 = 0.
