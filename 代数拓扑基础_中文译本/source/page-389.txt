Thus we have an induced operation on the quotient F/R. The module
properties are easily verified. We shall denote the resulting module by A⊗RB,
and call it the tensor product of A and B over the ring R. In addition to the
usual relations in A ⊗B, in A ⊗R B one has the relation
α(a ⊗b) = (αa) ⊗b = a ⊗(αb) .
Now let us consider a set map f : A × B →C that is a module homomor-
phism in each variable separately. Since it maps R(A, B) to zero, it induces a
homomorphism
g : A ⊗R B →C ,
which is actually a module homomorphism, as you can check.
Note that A ⊗R B is smaller than A ⊗B, because it is isomorphic to the
quotient group of A ⊗B by the subgroup generated by all terms of the form
(αa) ⊗b −a ⊗(αb) .
If f : A →A′ and g : B →B′ are module homomorphisms, then there is
a module homomorphism
f ⊗g : A ⊗R B →A′ ⊗R B′
mapping a ⊗b to f(a) ⊗g(b) for all a, b, because the map sending (a, b) to
f(a) ⊗g(b) is a module homomorphism in each variable separately.
The theorems of this section generalize to the tensor product of modules.
Proofs are left as exercises.
