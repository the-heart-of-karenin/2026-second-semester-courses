Definition 4.10.11 Suppose that a < b ∈R. Let p1, p2 : [a, b] →X be
paths in X with p1(a) = p2(a) and p1(b) = p2(b). We say that p1 and p2 are
homotopic with fixed endpoints, written
p1 ≃p2
rel {a, b} ,
if there is a homotopy function
F : [a, b] × [0, 1] →X
with these properties:
(1) F(t, 0) = p1(t), a ≤t ≤b;
(2) F(t, 1) = p2(t), a ≤t ≤b;
(3) F(a, u) = p1(a) = p2(a), 0 ≤u ≤1;
(4) F(b, u) = p1(b) = p2(b), 0 ≤u ≤1.
