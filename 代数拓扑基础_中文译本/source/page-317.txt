Definition 5.2.1 If A and G are abelian groups, then the set Hom (A, G)
of all homomorphisms of A into G becomes an abelian group if we add two
homomorphisms by adding their values in G.
That is, for ϕ, ψ ∈Hom (A, G), we define ϕ + ψ ∈Hom (A, G) by setting
(ϕ + ψ)(a) = ϕ(a) + ψ(a), for a ∈A. The map ϕ + ψ is a homomorphism,
because (ϕ + ψ)(0) = 0 and
(ϕ + ψ)(a + b)
=
ϕ(a + b) + ψ(a + b)
=
ϕ(a) + ψ(a) + ϕ(b) + ψ(b) = (ϕ + ψ)(a) + (ϕ + ψ)(b) .
The identity element of Hom (A, G) is the function mapping A to the identity
element of G. The additive inverse of the homomorphism ϕ is the homomor-
phism that maps each a ∈A to −ϕ(a). Thus we may refer to Hom as the
group of homomorphisms, but usually we will simply call it Hom.
EXAMPLE 5.2.2 The group Hom (Z, G) is isomorphic with G itself. Let-
ting I denote the isomorphism, we define I by setting I(ϕ) = ϕ(1), for all
ϕ ∈Hom (Z, G).
