Of course we need to check that the multiplication defined above is well-
defined, and that we really have a group. That is the content of the next
lemma.
Lemma 4.10.5 Let γ0 be the constant loop γ0(t) = x0 for 0 ≤t ≤1.
(1) The operation [γ] · [η] is well-defined.
(2) The operation of Definition 4.10.4 is associative.
(3) If γ is a loop, then [γ] · [γ0] = [γ0] · [γ] = [γ]
(4) If γ is a loop and η is defined by η(t) = γ(1 −t) for 0 ≤t ≤1,
then [γ] · [η] = [η] · [γ] = [γ0].
