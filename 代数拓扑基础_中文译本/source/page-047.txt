Lemma 1.6.4 The group Cp(K) is free abelian. A basis for Cp(K) can be
obtained by orienting each p simplex and using the corresponding elementary
chains as a basis.
Proof: The proof is straightforward. Once all the p-simplices of K are
oriented—each arbitrarily with no need to reference any other p-simplex—
then each p-chain, c, can be written uniquely as a finite linear combination
c =  niσi
of the corresponding elementary chains σi. The chain c assigns the value ni to
the oriented p-simplex σi, the value −ni to the opposite orientation of σi, and
the value 0 to all the oriented p-simplices not appearing in the summation.
The group C0(K) differs from the others in that it has a natural basis,
because each 0-simplex has only one orientation. The group Cp(K) has no
“natural” basis if p > 0, since one must orient the p-simplices of K in some
arbitrary fashion in order to obtain a basis.
Corollary 1.6.5 Any function f from the oriented p-simplices of K to an
abelian group G, extends uniquely to a homomorphism Cp(K) →G, provided
that f(−σ) = −f(σ) for all oriented p-simplices.
