To show the same result for a general path α, we proceed as follows.
Consider the singular 1-chain α −β, where β is the standard path as before.
It is a singular cycle of Sn since its boundary vanishes. In the case n > 1,

If n = 1 then we use the fact that the map π1 : S1 →P1 has degree 2. Since
