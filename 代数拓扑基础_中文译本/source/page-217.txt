Lemma 3.3.4.
If f : (X, A) →(Y, B) is a homotopy equivalence, then so are f : X →Y
and f|A : A →B. The converse does not hold, as the following example shows.
EXAMPLE 4.3.10 Consider the inclusion map j : (Bn, Sn−1) →(Rn, Rn \
0). Since Bn is a deformation retract of Rn and Sn−1 is a deformation retract
of Rn \ 0, the map j∗is an isomorphism in relative homology. Suppose there
existed a map g : (Rn, Rn \0) →(Bn, Sn−1) that served as a homotopy inverse
for j. Then, since 0 is a limit point of Rn \ 0, the map g necessarily carries 0
into Sn−1. Hence
g ◦j : (Bn, Sn−1) →(Bn, Sn−1)
carries all of Bn into Sn −1, so it induces the trivial homomorphism in homol-
ogy. On the other hand, this map is by hypothesis homotopic to the identity,
so it induces the identity homomorphism of Hn(Bn, Sn−1). We will shortly
prove that this last group is non-trivial, so we have a contradiction.
