4.9
∗Application: The Jordan Curve Theorem
Using the basic properties of singular homology, we now prove several classical
theorems of topology, including the generalized Jordan curve theorem and the
Brouwer theorem on invariance of domain.
Definition 4.9.1 If A is a subspace of X, we say that A separates X if the
space X \ A is not connected.
We are going to be concerned with the case where X is Rn or Sn, and A is
closed in X. Since X \ A is then locally path connected, its components and
path components are identical. In particular, the group H0(X \ A) vanishes if
and only if X \ A is connected. In general, the rank of H0(X \ A) is one less
than the number of components of X \ A. We will use this fact freely in what
follows.
Definition 4.9.2 A space homeomorphic to the unit k-ball Bk is called a
k-cell.
Theorem 4.9.3 Let B be a k-cell in Sn. Then Sn\B is acyclic. In particular,
B does not separate in Sn
Proof: Let n be fixed. We proceed by induction on k. First consider the case
k = 0. Then B is a single point. The space Sn \ B is a single point if n = 0,
while if n > 0, it is homeomorphic to Rn. In either case, Sn \ B is acyclic.
We now suppose the theorem holds for a (k −1)-cell in Sn. Let B be a
k-cell in Sn. Let h : Ik →B be a homeomorphism.
