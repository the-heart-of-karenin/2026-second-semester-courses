Now there is some set-theoretic difficulty with the concept of the “set of
all triangulations of a pair,” as there is with the “set of all sets.” We avoid
these problems by assuming that each Kα lies in some fixed space EJ. This is
justified by noting that if J is large enough, then each Kα has an isomorphic
copy lying in EJ. [For instance, we can let J have the cardinality of X itself.]
Once we know that all the sets Kα are confined to a fixed EJ, then we can
find a large enough index set for Kα.
