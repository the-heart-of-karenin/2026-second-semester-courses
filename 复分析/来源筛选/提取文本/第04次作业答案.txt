        2. Cartan’s uniqueness theorem / Cartan 唯一性定理


Problem / 原题

Prove the following Cartan’s uniqueness theorem.
证明下述Cartan 唯一性定理。

Let f be a holomorphic self-mapping of a bounded domain Ω.
设f 是有界区域Ω的全纯自映射。
Suppose that there exists z0 ∈Ωsuch that f(z0) = z0 and f′(z0) = 1.
假设存在z0 ∈Ω，使得f(z0) = z0 且f′(z0) = 1。
Then f is the identity.
则f 是恒等映射。

Hint. Without loss of generality, suppose that z0 = 0.
提示。不妨设z0 = 0。
Assume that f(z) = z + akzk + O(zk+1) with ak̸ = 0 for some k ≥2.
假设对某个k ≥2，有f(z) = z + akzk + O(zk+1)，其中ak̸ = 0。
Denote by fn the n-th iterate of f.
用fn 表示f 的第n 次迭代。
Apply the Cauchy estimates to fn to get a contradiction.
对fn 应用柯西估计以得到矛盾。

Solution / 解答

Replacing Ωby Ω−z0 and f by w 7→f(w + z0) −z0, we may assume that 0 ∈Ω, f(0) = 0, and
f′(0) = 1.
将Ω换为Ω−z0，将f 换为w 7→f(w + z0) −z0，便可假设0 ∈Ω、f(0) = 0 且f′(0) = 1。
Suppose, for a contradiction, that f is not the identity on Ω.
为导出矛盾，假设f 在Ω上不是恒等映射。

By the Taylor expansion and the identity theorem, there is a least integer k ≥2 with a nonzero
coeﬀicient in f(z) −z, giving the following local expansion.
由泰勒展开和恒等定理，f(z) −z 中存在一个系数非零的最低次项，其次数为某个k ≥2，从而有如
下局部展开。

                            f(z) = z + akzk + O(zk+1),       ak̸ = 0.

Let Fn = f◦n denote the n-fold composition; we claim that its expansion at zero is as follows.
用Fn = f◦n 表示f 的n 次复合；我们断言它在零点处具有如下展开。

                          Fn(z) = z + nakzk + O(zk+1),    n ≥1.

The case n = 1 is immediate.
当n = 1 时，断言直接成立。
If the claim holds for n, then Fn(z) = z + O(zk) and k ≥2 imply the following relations.
若断言对n 成立，则由Fn(z) = z + O(zk) 及k ≥2 得到下列关系。

               Fn(z)k = zk + O(z2k−1) = zk + O(zk+1),    Fn(z)k+1 = O(zk+1).
