# 复分析期中复习

本轮要求确认于2026年11月6日。成品为《复分析期中考试重点》和《复分析期中练习100题》两份PDF。

## 范围与资料用途

- 课堂范围以课程根目录的《复分析定理与证明.pdf》（36页）为主要线索，另明确包含幅角原理、Rouché定理、开映射定理和Hurwitz定理。整理稿经同学记录及AI填充，不能把所有补充均当作教师明确强调的内容。
- 课程没有已指定的统一标准教材。用户已几乎读完史济怀、刘太顺《复变函数》，会先读这本，因此用作优先阅读的理论参照；考试重点只补课堂与其之间的差异，不复写其经典基础内容。
- 其他八本参考书主要用作选题来源，并用于核实、补足待收录的课堂理论。不开辟额外理论体系，不将数学分析项目的书籍分类套用到本项目。
- 目前几乎没有期中难度信息。按用户判断，目标为稍高于作业。两份期末卷可辅助反推证明深度、多问结构及综合程度；不拟合期末专题，不据其扩大期中范围。
- 本次依据已有第1—6次作业共30组的风格选新题。初步主要出处完整匹配数为Simon 9、Lang 6、Stein 5、Gamelin 3，允许重复，不是教师实际取题次数，也不是九书全部出现频次的穷尽统计。

## 本次特定选题规则

- 100个连续题号：习题一1—60，习题二61—100；小问不另计数。
- 已有作业原题、仅换数值或记号的等价题不加入。已有两份期末原题也不加入。
- 非必要不改编题目：优先忠实选录原书，删除自行追加的追问，并以原书习题替换可被原题覆盖的自拟题。目标与条件须明确，保留原书数学任务。
- 仅保留题组共同标题；单题只列编号、来源及题面，不另拟小标题。
- 后段内容加重；第二节40题集中于零点计数、局部映射、Hurwitz、奇点及相关综合。
- 练习册按完整题面交付，不默认附解答；笔记与题集中的理论背景允许互相支持，但不重复列出同一道练习。

## 文件与修改入口

- `复分析期中考试重点.pdf`：教材对照、差异内容的结论及必要证明。
- `复分析期中练习100题.pdf`：60+40两节练习，含每题来源和改编说明。
- `源码/notes.tex`、`源码/exercises.tex`：直接修改入口，没有生成器覆盖源码。
- `源码/来源清单.md`、`源码/题目来源.csv`：由题集源码提取的来源映射；修改题面或来源后同步更新。
- `源码/审校记录.md`：去重范围、近似题辨析及数学条件核查记录。
- `源码/build.ps1`：在纯ASCII临时路径编译三遍，使目录及交叉引用稳定，再复制成品回本目录。
- `源码/build/`：本次编译日志及目录、交叉引用中间文件。
