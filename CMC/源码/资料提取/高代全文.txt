题型一 矩阵的运算


   矩阵的运算中需要注意矩阵乘法不满足交换律，同时矩阵中有零因子存在，即两个非零矩阵

 乘积可以等于零矩阵。概括起来，以下几点需要特别注意：


（1）一般地，二项式定理
               Xn  n
                             (A + B)n =       AiBn−i
                                                                       i
                                                     i=0

   不一定成立。但若A, B 可交换，即AB = BA，则上式成立。

（2）矩阵乘法没有消去律，即CX = CY （或XC = Y C）推不出X = Y 。但是有如下特别结

   论：

   （i）一个矩阵C 左可消当且仅当C 为列满秩，即以下两条陈述等价：

    （a）由CX = CY 可推出X = Y 。

    （b）C 是列满秩，即C 的列向量组线性无关或者rank(C) = C 的列数。

  （ii）一个矩阵C 右可消当且仅当C 为行满秩，即以下两条陈述等价：

    （a）由XC = Y C 可推出X = Y 。

    （b）C 是行满秩，即C 的行向量组线性无关或者rank(C) = C 的行数。

   （iii）A2 = E 推不出A = E 或A = −E，即A2 −E = (A + E)(A −E) = O 推不出

       A + E = O 或A −E = O。


【例1.2.1】设A, B 均是n 阶方阵且满足A2 = A，B2 = B，(A + B)2 = A + B，求AB。

 解由(A + B)2 = A + B 得到

                          A2 + AB + BA + B2 = A + B.

 又A2 = A，B2 = B，所以

                         AB = −BA,

 从而

                       A · AB = −A · BA,

 即

                        AB = −ABA;

                       AB · A = −BA · A,

 即

                  ABA = −BA 或 BA = −ABA,

 因此

                         AB = BA.
