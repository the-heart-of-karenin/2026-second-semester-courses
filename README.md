# 学习资料与记录工作区

这是一个数学学生的学习工作区，也用于其他课程和独立读书。这里保存用户提供的资料、课程笔记、作业标准答案及复习材料。

**后续 AI 接手时，先完整阅读本文件。不要依赖自己能看到此前的聊天。** 本文件记录截至 2026-10-31 已确认的使用约定；用户后续的明确要求优先。

## 1. 按实际学习内容工作

- 一个文件夹可以代表一门课程，也可以只代表一本正在阅读的书。
- 课程中可能有教材、参考书、作业、大纲、真题，也可能只有一本书。独立读书时，按实际需要编写读书笔记。
- **没有作业、真题、大纲或考试安排完全正常。不要要求用户补齐一套课程资料，也不要为缺少这些材料而停下工作。** 按已提供的材料和当前任务处理即可。
- 按需创建文件夹和文档。没有相应内容时，不预建大量空目录、空记录或复习计划。
- 用户直接在对话里给出的题目、截图或问题表述也属于可用材料，不以先上传一份作业文件为开始讨论的前提。
- 不推测用户未提供的题目，不把教材中没有被布置的习题擅自当成作业。只有当前讨论确实需要某段缺失内容时，才请求必要的题干或上下文。
- 用户询问英文单词、术语翻译、词义、读音或用法，通常只是临时替代查词典。这类英文相关内容一律只在聊天中回答，不写入任何学习记录或 PDF；即使同一段数学讨论后来被要求记录，也要略去这些英文问答，除非用户以后明确撤销本条规则。
- 这是轻量的学习辅助，不是学习管理系统。无需持续跟踪熟练度、安排打卡或为每个知识点建立掌握状态。

## 2. 对话与文档写入的边界

**日常提问默认只在聊天中回答。** 用户明确要求编写、录入、整理、修改笔记或答案，以及生成、更新 PDF 时，才修改相应文件。另有一项例外：发现已交付答案存在已确认的实质错误时，按第 4 节的纠错规则直接修正。

收到文档写入任务后：

1. 确认当前课程或书籍、所用资料、任务范围及需要修改的文件，优先复用已有文档。
2. 按要求直接编写或修改笔记正文、标准答案或复习材料，不将聊天逐轮转写为问答记录。
3. 修改 LaTeX 源码后编译受影响的文档，交付实际生成的 PDF 及相应源码入口。

不维护临时问答块，不因换题、换书、结束讨论或下次接手而扫描、整理历史提问。现有笔记和答案按当前明确任务修改，答案纠错依上述例外处理。

## 3. 文件归档与去重

收到文件后，可以先基于它回答问题；只有用户明确要求保存、归档或记录时，才写入工作区并进行去重。

- 根据当前对话、文件内容和已有目录，判断它是书籍、参考资料、作业、真题、大纲或其他材料，放入相应课程或书籍目录。
- 文件已在合适的位置时直接复用；聊天附件可以访问时，将其保存到工作区，不让后续记录仅依赖临时附件。
- **同一本书，或内容相同的文件，只保留一份。** 不能仅凭文件名不同、格式不同或文件哈希不同就视为新资料。
- 默认复用已保存的版本，重复上传不再额外入库，也不为每本书维护多套版本。需要以新版本替换时，先确认不会丢失已有批注等独有内容，再保留一个明确的主文件。
- 同一本书被多处引用时，引用已有文件，不为阅读记录或另一份答案再次复制。
- 确实无法判断归属时，可以先放入资料根目录的 `待归类/`，再向用户简短确认。单独读一本书本身就是完整的使用场景，不需要强行归到某门课。
- 文件无法访问、题目无法辨认或某页缺失时，如实说明具体缺少的部分，不假装已经归档、读过或完整提取。

下面是可采用的目录示例，**不是必须建齐的模板**。已有清晰的目录结构时沿用它。

```text
2026下半学期课程/
├── README.md
├── 某门课程/
│   ├── 教材与参考资料/
│   │   └── 某本书/
│   │       ├── 原书.pdf
│   │       ├── 阅读记录.pdf
│   │       └── 源码/
│   │           ├── 阅读记录.tex
│   │           └── build/
│   ├── 作业/
│   │   └── 第03次作业/
│   │       ├── 作业原件.pdf
│   │       ├── 第03次作业答案.pdf
│   │       └── 源码/
│   ├── 课程信息/
│   ├── 历年试题/
│   └── 复习/
│       ├── 作业总结.pdf
│       └── 源码/
└── 单独阅读的某本书/
    ├── 原书.pdf
    ├── 阅读记录.pdf
    └── 源码/
        ├── 阅读记录.tex
        └── build/
```

文件名优先清楚、稳定；上传材料的原始名称有辨识度时保留，不必机械地改成示例里的名称。PDF 放在便于打开的位置，源码、图片依赖和编译中间文件收在相邻的 `源码/` 内，不与阅读用 PDF 混成一堆。源码也可按需要打包，但应保留便于后续编辑的版本。

### 用户提供的对话记录

用户有时会提供一份与 AI 的对话记录，作为接手和整理学习内容的材料：

- 先阅读并判断记录是否完整：最初的问题、必要题干与上下文、相关回答和追问是否齐全，有无明显截断或缺失。对话仍有未解决的问题，不等于记录本身不完整；无法确认完整性时如实说明，不猜补缺失内容。
- 记录完整时，根据讨论内容、教材或题目出处以及已有目录，自行判断属于哪门课程、哪本书或哪个章节，并确定合适的存放位置。通常能从内容判断出来，不必例行要求用户指定课程或路径；只有确实无法判断时才简短确认。
- 仅在用户要求归档或整理笔记时写入文件，已有对应文档时复用并更新。要求整理笔记时，提取所需定义、结论、推导与解答，直接组织为笔记正文，不保留逐轮问答格式。
- 记录不完整时，指出具体缺少的内容；仅在影响理解或整理时请求补充必要部分，不把片段当成完整对话处理。

## 4. 各类记录的用途

### 作业：先形成独立的标准答案，再按需讨论

用户通常先要求一份作业的标准答案，随后可能针对其中的题目提问。按以下方式处理：

- 用户要求整份作业解答时，生成该份作业独立的 `第XX次作业答案.pdf`，放在该次作业目录中，并保留可修改的 LaTeX 源码。
- 按原题顺序收录完整题干及必要条件，保留题号，注明作业次数及教材出处，给出规范、完整的解答。缺失题干或尚未解出的部分须明确说明。
- 作业引用教材习题时，从已有教材核对题干；无法取得完整题干时注明缺失，不自行补造。
- **保留题目的原始表述，不擅自改写、补充或修正题干，包括公式、符号和图表。** 若题目有错误、遗漏、歧义或需要补充条件，在原题之后另行说明，并交代解答采用的理解。
- 用户要标准答案可能是为了核对自己已做的结果；不能据此判断其掌握程度，也不建立“不会的题”或误区追踪记录。
- 后续针对某道题的提问默认在聊天中解答，不自动生成作业问答记录。新增解释、其他解法或教学补充，只有在用户明确要求修改答案或加入笔记时才融入正文；已确认的实质错误按下一条处理。
- **已交付答案纠错是默认不改文件规则的例外。** 发现答案存在已确认的计算错误、推理错误、遗漏必要条件等实质错误时，直接修正对应源码并更新受影响的 PDF，无须再次等待写入指令；向用户简要说明更正位置和内容。已有其他文档引用了同一错误结论时，同步修正已知的受影响内容。尚未确认的疑点应先核实，不以个人表述偏好作为纠错理由；单纯增加解释或其他解法仍须按明确写入要求处理。

### 读书笔记：按书籍与章节组织

- 用户要求编写读书笔记时，按书籍复用或建立对应文档，不因上传或询问一本书就自动创建笔记。已有 `阅读记录.pdf` 等文件可继续沿用。
- 按原书的章节、节、定理、例题、习题或页码顺序安排条目，像放在对应书页旁边的电子批注，不按聊天时间不断往末尾堆积。
- 每条注明足够准确的出处。原书页码与 PDF 页码不一致时区分两者；不确定的编号不要猜。
- **用户已给出原书页码时，直接采用，不再为了核对页码或补充 PDF 页码而翻查、检索原书 PDF。** 只记录原书页码即可。仅在用户明确要求核对原文，或解答确实缺少必要上下文时，才查阅相关页面。
- 根据用户要求直接组织定义、命题、公式、推导、证明或例题；保留理解内容所需的条件和上下文，不要求保留提问历史。整理范围由当前任务决定。
- 同一本书某处已有记录时更新那一处，不因换了对话而另建一份阅读记录。
- 《应用随机过程》的 随机过程/源码/阅读记录.tex 中，FROZEN_PROOF_BEGIN id=sp-renewal-series-standard-proof 至对应 FROZEN_PROOF_END 是用户要求逐字保留的标准证明。后续整理其他内容时不得改动该区间的文字或公式；需要补充说明时写在区间外。只有用户明确要求修改这段证明，才可更改。

课堂笔记、读书笔记及其他学习材料按实际来源组织，不强行归入作业答案。用户自行提供的笔记与要求 AI 编写的笔记，均直接维护正文。

### 用户提供的笔记：识别并录入 LaTeX

用户要求“帮我整理笔记”，并提供手写、截图或其他形式的笔记时，识别笔记内容并写成 LaTeX 源码。按以下规则处理：

- **每次更新 LaTeX 源码后编译，并确认编译成功；默认不渲染或查看 PDF 页面，不做视觉排版检查。** 编译状态与错误日志的检查照常进行，具体边界见第 9 节。首次录入及后续修改均交付源码及实际生成的 PDF。
- **同一门课程的笔记集中写在一个 `.tex` 文件中，不按课次拆分文件。** 用户会用 `lectureXXX` 表示课次顺序，按这些标识在同一个文件中组织和追加笔记。
- **第一次录入以忠实保留笔记内容为主。** 保留原文、公式、条件及推导，不擅自删减、改写或扩展证明；但可适当补全省略号或明显简写所省略、且能从当前笔记明确确定的公式项及简短衔接，使内容便于阅读，不必机械保留所有省略号。无法确定的省略内容不猜补；涉及实质性纠错或新增论证时，按用户的进一步要求处理。
- 识别不清楚的文字、符号或公式片段，先结合上下文作合理推测，按推测内容录入，不必等待确认再写入；交付时须明确列出具体位置和推测内容，询问用户是否正确，不将推测表述为已确认的识别结果。能够辨认的其余内容照常录入。
- 首次录入后的提问默认在聊天中回答；用户明确要求将讨论内容写入笔记或修改笔记时，**直接改在笔记正文中，不用批注的形式，也不套用临时“问 / 答”记录格式。**
- 不自行添加 remark；只有用户明确要求加 remark 时才添加。

## 5. 日常解答与笔记编写

回答的程度服从当次请求：要求完整解答就给出完整解答，要求提示就只给提示。不因提问推断用户的掌握程度。

需要笔记时，按用户提供的内容或指定范围直接编写 LaTeX 正文。用户要求把某次解释加入笔记时，将必要结论、公式与解释融入对应位置，不建立临时问答及后续收尾流程。

### 数学内容的来源与表述

- **区分原文引用、等价改写与补充内容。** 原文引用须忠实保留原书表述并注明出处；等价改写不得改变假设、量词、结论或适用范围。自行增加的条件、解释、纠错和推广，应明确标为补充条件、补充说明或修正表述，不能直接套用原书定理编号而使人误以为是原文。
- 原书表述存在遗漏、歧义或错误时，分别说明原书如何陈述、补充或修正了什么，以及理由。尚不能确认的问题须说明不确定性；不能将自己的推断冒充教材结论。此规则不授权擅自改动用户要求忠实录入或逐字保留的内容。
- **采用完整、明确的数学叙述，不以缩短篇幅为目标。** 给齐对象、条件、公式与结论，必要时说明推导关系。标准化不等于速记化，不用堆叠提醒代替具体内容，也不因追求简短而省略关键逻辑。
- “补回”“单列”“另验”等词不能独立代替说明。涉及求解时，应写清哪些解因换元或除法被排除、哪些解已由公式中特定常数取值得到、哪些解不能由该公式表示，以及应检查的定义域或区间条件。已有叙述足够清楚时，不必反复解释同一理由。

## 6. 文档修改与删除

- 用户明确要求修改或删除内容时，直接处理指定文档中的对应内容，并维护有效引用、目录和编号；修改 LaTeX 后重新编译。
- 删除指定内容时，不留下替代性的摘要或聊天备份。删除范围不自动扩大到原书、原始作业附件或其他独立文件。
- “不用记录”“这个问题别记录”表示只在聊天中回答；没有明确要求删除既有文档内容时，不据此删除旧笔记或答案。

## 7. 文档引用

同一 PDF 内优先使用稳定标签和内部链接；跨 PDF 时给出文件链接及明确的章节、题号或条目标识。修改、删除或移动内容时，维护受影响的引用。

## 8. “总结作业”命令

用户说“总结作业”或提出同义要求时：

1. 默认分析当前课程已经收到的全部作业；用户指定次数、章节或范围时按指定范围处理。
2. 读取原始作业、教材中对应的已布置题目，以及已有的独立答案。**不能只依据聊天中问过的题或个别笔记概括全部作业。** 必要时在此次总结中提取、合并完整题目，不要求此前就建好全集。
3. 生成独立的 `作业总结.pdf`，通常放在该课程的 `复习/` 中，源码另收在相邻子目录。
4. 重点从全部作业中归纳老师的出题习惯：常考查的概念和主题、反复出现的题型、典型解法、证明或计算的要求、对条件和反例的重视程度、知识点如何组合等。
5. 用具体作业次数和题号支持判断；材料允许时给出出现次数或分布。用户已经会做但反复出现的题型同样属于复习重点。
6. 根据上述规律给出复习重点、代表题和练习建议，按需要补充相关概念辨析与易错条件，不建立个人误区追踪。要区分作业中可直接观察的规律与对考试的推测。

同一题在不同次作业中被重复布置，是出题习惯的证据；同一份文件被重复上传，不重复计数。资料不完整时按实际范围总结，不编造频次或假称覆盖整学期。

没有收到作业就没有这一项工作；不因此要求独立读书的用户补作业。也不默认到期末就把全部学习资料强行重新总结一遍，按用户的命令和实际需要生成。

## 9. LaTeX、PDF 与交付

- 用户提供的笔记识别与整理按第 4 节“用户提供的笔记：识别并录入 LaTeX”执行；编译成功确认与视觉检查的边界统一按本节执行。
- 学习记录、数学答案和作业总结采用 LaTeX 编写并编译为 PDF；本 README 及普通归档说明使用 Markdown 即可。
- 首次需要编译时检查本地实际可用的 LaTeX 工具链，不根据聊天界面的公式显示情况推断能否编译。中文文档可优先采用 `ctexart` 与 XeLaTeX，按环境选用可用字体和工具。
- **Windows 下，只要 LaTeX 源码或课程目录的路径中含有中文，就不要先在原路径尝试编译。** 此环境会稳定触发路径解析或日志、字体缓存写入问题；应从一开始就把待编译的 `.tex` 及其依赖复制到一个路径和文件名均为纯英文 ASCII 的临时目录，在该目录内编译。不要把失败一次再改临时目录当作正常流程。
- 英文临时目录应位于系统临时目录或工作区内专门的临时位置，路径尽量不含空格、括号和特殊字符，例如 `%TEMP%\codex-latex\reading-notes\`；入口文件也使用 `notes.tex`、`homework.tex` 等英文名。需要缓存的引擎还应把缓存目录设为其中可写的纯英文子目录。
- 编译成功后，把最终 PDF 复制回约定的中文课程目录；将需保留的日志或中间产物放回对应 `源码/build/`。原始 LaTeX 源码仍按课程结构保存在 `源码/`，无需为此重命名用户的课程文件夹。若整个源码路径本来就是纯英文 ASCII，才可直接在源码目录内编译。
- 源码放在 `源码/`，中间产物放在其 `build/` 等子目录。将成功生成的最终 PDF 放到约定的阅读位置。
- 每次更新、总结或删除源码之后，编译相应文档一次。
- **编译成功确认属于必要步骤：** 检查编译命令是否成功结束，读取必要的错误日志，确认目标 PDF 已由本次编译生成或更新。编译错误须处理或如实说明，不交付旧 PDF 冒充本次结果。
- **视觉排版检查默认不执行：** 不为检查排版而打开 PDF、渲染页面或逐页查看；用户明确要求检查时再做。这里的“不检查 PDF”不包括上一条的编译状态、错误日志及输出文件更新检查。
- 缺少编译环境或编译失败时，如实说明，保存完整源码并处理具体障碍；需要用户操作或授权时说明具体事项。**在实际生成前，不能宣称 PDF 已完成或已更新，也不能默默把只写出源码视为交付完成。**
- 执行写入命令后的聊天回复，以简短说明和可点击的最新 PDF 文件链接为主；纯对话时直接回答即可。需要指出编译障碍、材料缺失或尚未解决的问题时直说。

## 11. 考试复习重点与配套训练的可复现流程

本节记录跨课程通用的复习材料工作要求。具体考试范围、题量、教材约定和本轮删改记录，放在对应课程的复习目录中，不作为所有课程的统一要求。

### 资料、范围与考试依据

**复习材料以考试为导向。生成复习材料之前，先问用户：“现在对考试难度了解如何了？”** 了解老师的说明、已知题型与难度，以及当前可用的考试依据，再确定材料的详略、重点和选题难度；用户已在本次请求中说明时直接采用，不重复询问。根据资料情况分别处理：

- **有历年真题、老师明确的考试范围和作业时：** 在今年已确认的范围内，优先拟合真题的题型、难度、证明深度和知识点组合。先根据材料初步判断作业与真题的相关程度，再简短询问用户作业与考试的相关程度如何，以校正训练重点；不默认作业难度、题型及覆盖范围等同于考试。
- **缺少真题，主要有教材、参考书、课堂笔记和作业时：** 综合判断这些材料，尤其是课堂实际讲授内容、老师强调的结论和作业要求，并结合已确认的考试范围安排复习。遵守下文的书籍用途分类，不把参考书自身的难度直接当成考试难度；明确哪些判断有材料依据、哪些只是暂时推测。
- **真题内容超出今年考试范围时：** 可能是该年份的教学进度或考试范围与今年不同，先简短询问用户以确认；不能仅凭往年真题就扩大今年的复习范围。

1. 先阅读本 README 与课程目录，列出教材、习题集、全部原始作业、修订稿、已有答案及已提供的历年试卷；核对内容去重，修订稿优先，保留独有题目。其他课程的资料不混入。
2. 以用户明确的考试截止章节为边界，在成品中醒目标明是否包含截止节。不能因为作业、试卷或参考书涉及更多内容，就自行扩大考试范围；已观察的作业范围与已确认的考试范围分别记录。
3. 实际读取范围内的教材内容与全部相关作业，建立“作业文件/原题号—考点—教材章节”清单。扫描件用页面图像核对，不将乱码或提取空白视为无内容；不以二手概括代替原文。
4. 有历年试卷时，先分析大题结构、分值及计算、证明、辨析、应用等要求，再调整重点与训练配比。重要性依据具体作业、真题及知识依赖判断，区分资料中的事实与对考试的推测。

### 首次建立复习项目：确认三类书籍的用途

1. **第一次建立某门课程或某个范围的复习项目时，仍须向用户询问并确认书籍分类。** 先列出拟用资料及初步分类，让用户说明哪些属于下述三类；不能因文件名、权威性或已上传就自行认定用途。已明确的部分直接沿用，未明确的部分简短询问，可先处理不依赖分类的工作。
2. 书籍按本项目中的实际用途分为三类：
   - **标准教材：** 上课所依据或用户指定为复习主线的教材。笔记以其内容范围、概念、方法和记号为主；用户复习时主要对照这些书。
   - **外来教材：** 仅供补充参考。只有确有标准教材未覆盖、与当前主题相关且值得补入的新定理或结果时，才少量纳入笔记，并另列来源。可以从中选择习题；不将该书的理论体系整体混入笔记，也不因它提供了同一结果就重复摘录。
   - **纯练习来源：** 只用于选取习题，不作为笔记的理论来源。即使原书本身是教材，只要用户在本项目中仅把它当练习册，也按此类处理；用户不需要阅读该书，不能只给题号或引用让用户自行翻阅。数学分析项目中的 Stein 一书，用户已明确没有阅读且不准备阅读，按纯练习来源处理。
3. 这项分类依据是用户希望该书在本项目中承担什么作用，不只依据“用户会不会阅读”。经典教材也可能只是外来教材或纯练习来源；同一本书在不同项目中的用途可以不同，不把某门课的分类套用到其他课程。
4. 在对应课程复习目录的说明中保存已确认的分类。后续更新沿用，不必每次重复询问或逐本汇报；新增资料用途不明或用户改变用法时，再确认相应部分并更新说明。

### 复习重点的写法

1. **复习笔记以上课教材或用户指定的标准教材为主线，外来教材只少量补充有价值的新定理。** 保留标准教材的概念、方法和适用范围，给齐定义、假设、结论与公式。可以按章节或专题组织，不强制逐章照搬原书顺序，也不因专题编排而要求重排现有文档；主线是内容依据与范围，不是僵硬的目录顺序。作业及此前讨论按需要作为有明确出处的补充，纯练习来源不进入笔记的理论正文。
2. 关键公式直接写出，不能只说“用某公式”“作某换元”。可化归的方程或题型，应明确列出类型、适用条件、换元关系及代表例子；重要的特殊结论应分别陈述。
3. 公式的变量、参数、任意常数和积分上下限要明确。重复出现的原函数应说明是否采用同一选择；更换约定时，说明常数是否需要重新确定，避免符号相同却含义不同。
4. 只在真正重要之处强调，不给每个条目都重复贴“重点”标签。内容详略按上述三类资料处理：
   - **标准教材中已有的结果：不重复写证明，严格叙述结论并注明出处即可。** 定义、假设、量词、结论和适用范围必须完整、标准、准确；必要时贴近原书表述，不为压缩篇幅改成含糊概括。出处注明书名简称及可核对的章节、定理编号或页码，不猜编号。即使结果重要或考试可能考证明，也以提醒回看书中对应证明为主；只有用户另行明确要求在复习重点中写出证明时才补写。
   - **外来教材中确有必要补入的新定理：少量选择，并写成可独立阅读的补充块。** 严格陈述结论，注明具体来源，补足必要解释、推导与证明，使用户无需另读整本外来教材也能理解和使用。先判断是否确有新的、有用的内容，再决定写入；不能因为用户不会翻该书，就把它的大量理论和证明搬进笔记。用户明确要求暂不附证明等时，服从该次要求。
   - **纯练习来源：只用于题集，不编入复习笔记的理论正文。** 选题应给出完整题面、条件、符号、目标及准确出处，不能要求用户阅读该书的正文才能理解题目；必要背景应按课程教材的语言在题面中交代。用户另行明确要求讲解或收入某项理论时，再按该次要求处理。
   - 同一结果已能在标准教材中找到时，优先引用标准教材，不因外来教材或练习来源也有此结果而重复展开。作业、讨论及自行推导的补充仍须紧扣主线、注明性质，并写清必要的条件与推导。
5. 以教材和用户指定的处理方式统一记号、定义与所选工具，不为展示全面性堆入用户不需要的平行定义或额外推广。具体取舍仅作用于对应材料，不提升为其他课程的固定规则。
6. 遵守第 5 节的数学内容来源与表述要求：原书陈述与自行补充分别标明；采用完整数学叙述，不以速记措辞或含糊提醒替代具体条件与结论。

### 内容块的出处标注与排版

**出处不仅用于标注，也决定内容的收录范围：不能仅因某种方法与教材内容相关、能将例题归入更一般的类型，就主动引入指定材料未讲述的命名方法或分类。** 这类内容应由用户的具体提问或明确补充要求引出，介绍时说明来源及其与教材的关系；是否写入笔记仍按用户的记录要求处理。

1. **出处放在对应内容块的开头；同一来源连续写几段时只标一次，切换来源时再标。** 一个知识点可以依次包含标准教材、作业、外来教材新定理或讨论补充，不把不同来源揉成无法辨认的一段。无需每条公式重复标注，也不能只在整节末尾集中列几个书名来代替对应关系。
2. 来源标签采用短方框或加粗短标签，正文接在后面，后续自然续行；不把整段正文装进大框，不要求做成多列表格。书籍通常写书名简称与节号，有准确的定理号或页码时按需要补充，不必同时堆满所有定位信息。作业写次数与题号；讨论或自行推导写“讨论补充”或“补充推论”，并交代针对什么问题。出处不能虚构。
3. 例如：`【教材·§5.2，定理5.2.5】`后陈述教材结论；转入应用时另起`【作业4·第13题】`；确有外来新定理时另起`【补充·某书§…】`；相关讨论另起`【讨论补充】`。同一结果有多个来源时，优先标标准教材；其他来源只有提供确有必要的新内容时才另列。没有相关补充时，只写教材内容，不为凑版式新增内容块。
4. **各块正文基本遵循该来源的实际内容，并区分原文、等价改写和补充。** 教材块按教材标准叙述；作业块指出具体题目与当前内容的联系；外来教材块交代新增结论来自何处以及与教材内容的关系；讨论补充写明相关问题或结论，不追踪提问历史。文首先列书名简称与资料位置，避免正文反复出现长书名及文件路径。
5. 补充应服务于主书内容，例如指出作业中的对应应用、补足确有必要的条件、介绍来源明确的另一种解法。**不能仅因看到相似题目就发散添加无关推广、额外分类、个人化提醒或新的知识体系。** 对原书的修正须明确标明，但不能悄悄将补充条件写成原书原文。
6. 使用多本主书时，应在文首先说明各书覆盖的内容，并在各块开头标清具体来源；不必为了保留来源而重复抄写同一结果。以上为后续编写与修改的通用要求，不据此自动重排现有文档，只有用户要求修改相应笔记时才应用。

### 配套训练的选题与题面

1. 按用户要求确定题量，在指定习题集中实际寻找相近题，核对原题号、完整条件、原书页码及 PDF 页码。题量可随后续明确要求调整，不为维持最初数量拒绝必要补充。
2. 以考试要求组织训练，减少重复的机械计算，兼顾基本概念、定理证明、条件辨析、综合求解及教材中有代表性的应用问题。有新方法、新结构或新考点的题值得保留，不能仅凭题目外观相似去重。
3. 用户要求录入某道题或一组小问时，先检查是否已收录，再核对题干，避免漏项或重复。按实际请求选择、合并或追加；不要擅自把选题任务扩成完整答案集。
4. 题面采用标准试题语言，给齐条件、符号、求解或证明目标；必要时直接列出待证等式、不等式，多项任务分编号。不要用引导性语言代替题目，不在题干中夹入解法提示或暗示结论。
5. **非必要不对题目本身做出改编，优先选用并忠实保留原书题目。** 沿用原题的假设、结论、小问结构和任务范围，不为增加难度、显得完整或凑题量而自行加强结论、更换条件、添加追问；能找到合适原题时，不以自拟题替代。翻译和排版调整不得改变数学任务。确需消除歧义、处理原题错误或适应用户明确范围时，只作必要调整，在题面外说明原文、调整内容及理由。原题、改编题、自拟题明确区分，不能用自拟题冒充书中原题，也不能只列题号而不给可独立使用的题干。

6. **复习笔记 PDF 或考试真题中已经出现的题目，不再收入配套题集 PDF。** 用户会优先阅读前两类材料，题集应提供补充训练，避免重复。选题时对照现有复习笔记和真题，按实际题目内容去重，不仅按题号或出处判断；仅换记号、数值或拆分小问而实质相同的题，也不重复收入。真题仍用于判断题型、难度与重点，不因此直接搬入题集。
7. **适当提高作业题在题集中的占比。** 结合已判断并向用户确认的作业与考试相关程度，优先选入有代表性、符合考试范围的作业题，不为增加外部习题而挤掉这些题。作业题若已出现在复习笔记或真题中，仍按上一条去重，不重复收入。

8. **题目叙述须严格，明确对象、全部条件及具体目标。** 应清楚说明要求证明的命题、计算的表达式、确定的集合或构造的对象，避免“分析一下”“说明相关性质”等模糊任务。原书已有叙述时主要遵循原书，不以“更严格”为由新增数学要求；原文确有歧义时，在题面外另作必要说明。
9. **只为题目组设置共同标题，不为单道题另拟小标题。** 单题保留编号、来源和完整题面即可；来源信息不作为题目小标题。

### 源码、交付与后续更新

1. 交付复习重点与训练题 PDF，保留可修改的 LaTeX 源码、题库主源、来源清单及编译说明。若存在生成脚本，明确哪份文件是修改入口，避免直接修改生成文件后被覆盖；不能只留下 PDF 或公式截图。
2. 各章节、知识点、题目采用稳定标识。后续追加或删除时，优先保留原编号及有效引用；用户明确要求不重编号时照做。删除指定内容应实际移除正文，不留下替代性摘要。
3. 更新沿用原文件与目录，同步维护题量、标题、来源映射、说明及源码包，避免生成多套内容重复、版本不明的成品。先检查新资料是否属于考试范围，再分析版本差异并修改对应位置。
4. 修改源码前确认对应文档和本次任务范围，按本 README 的文档规则处理。中文路径下在 ASCII 临时目录编译，PDF 放课程复习目录，源码及依赖放相邻源码目录；编译、检查与交付遵循本 README 及当次适用的工具要求。
